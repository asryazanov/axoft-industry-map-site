# Карта промышленного предприятия Axoft

Демонстрационный каталог: подбор по задаче, роли, продукту или зоне, список и карта, подготовка запроса в файл.

Запросы не отправляются в Axoft. Подборка содержит классы решений, позиции каталога служат справкой.
